# Security policy

## Reporting a vulnerability

Email **hello@atharvav.com** with a description of the issue, steps to reproduce, and the commit you tested. Please do not open a public issue for vulnerabilities in the code or its dependencies.

You will get an acknowledgement within a few days, and a fix or a mitigation plan once the report is confirmed.

## Detector bypasses

Inputs that get past the detector are expected and useful: they become benchmark cases. Send them the same way. If a bypass contains no harmful content and no private data, a regular issue is fine.

## Supported versions

PicoPike has no releases yet. Only the `main` branch is supported.
